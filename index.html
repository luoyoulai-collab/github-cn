让 GitHub 变中文（Google 浏览器 · 二选一）

方案一：Chrome 自带翻译（设置一次，点链接自动变中文）
  1. 把 chrome://settings/languages 复制粘贴到地址栏，回车
  2. 打开「使用 Google 翻译」开关
  3. 用 Chrome 打开 github.com，点地址栏右侧的翻译图标，选「中文（简体）」
  4. 在翻译弹窗里点「更多选项」，勾选「始终翻译英文」
  5. 完成！以后从本页点任何 GitHub 链接，页面打开就自动变中文

小提示：机器翻译偶尔会把代码、人名也翻掉，追求更地道的推荐方案二。

方案二（推荐）：汉化插件，两次点击装好，术语最准
  1. 点下面第一个按钮，在 Chrome 商店页点「添加至 Chrome」
  2. 回到本页，点第二个按钮，弹窗里点「安装」
  3. 刷新 GitHub 页面，整站自动中文（跳转后依然生效）
① 安装 Tampermonkey 扩展Chrome 应用商店（"油猴"脚本管理器） ② 一键安装 GitHub 中文化脚本装好 ① 后点这里，弹窗点「安装」即可

脚本来自开源项目 maboloshi/github-chinese（3.4 万星，GPL-3.0 协议），本站仅托管分发。

装好没反应？最常见原因：Chrome 没开「允许用户脚本」。开启方法：地址栏输入 chrome://extensions 回车 → 找到 篡改猴(Tampermonkey) 卡片 → 点「详情」→ 打开「允许用户脚本」开关 → 回 GitHub 按 Ctrl+F5。（点 Tampermonkey 图标若弹出蓝色提示条，点上面的"点击这里了解如何操作"也能到同一位置。）

旧版 Chrome 则是开「开发者模式」：chrome://extensions → 右上角「开发者模式」。仍不行就点右上角 🧩 → Tampermonkey → 管理面板，确认列表里有「GitHub 中文化插件」且开关打开；没有的话重新点上面的「② 一键安装」按钮。

用 Edge 的话（顺带一提）
  1. 打开 github.com → 地址栏右侧翻译图标 → 选「中文（简体）」→ 勾选「始终翻译英文网站」
