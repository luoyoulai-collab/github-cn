# GitHub 中文助手

常用入口 + 汉化方案 + 英文对照表。**线上地址：https://luoyoulai-collab.github.io/github-cn/**

只做显示层翻译，操作和账号都是原生 GitHub。

- 汉化方案一：Chrome 自带翻译（设置"始终翻译英文"后，点链接自动全中文）
- 汉化方案二：Tampermonkey + [GitHub 中文化插件](https://github.com/maboloshi/github-chinese)（GPL-3.0，本仓库 `github-chinese.user.js` 为其托管副本，一键安装地址：https://luoyoulai-collab.github.io/github-cn/github-chinese.user.js ）
